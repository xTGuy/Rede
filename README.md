# Rede

Rede is a untethered exploit for iOS 14+ that exploits the Web Clip feature in iOS to jailbreak you iDevice. Rede is also not usable when internet is not present, but we are currently trying to make a offline version of Rede. Rede is accesible using the RidgeJB jailbreak tool but currently the tool is not ready.

# Q&A

What does Rede do?
  Rede can help jailbreak tools like RidgeJB function.
How do I install Rede?
  Rede can be installed manually, but it is not recommended unless you are making a jailbreak tool with Rede
Why is Rede better than other exploits?
  Rede is the only exploit that works with every version 14+ and is very easy to setup!
